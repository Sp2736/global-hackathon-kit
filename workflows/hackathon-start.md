# Hackathon Start

## Description

Rapidly understand a surprise hackathon problem and create a bounded implementation plan.

## Steps

1. Inspect the repository and current stack.
2. Read all project-specific instructions.
3. Restate the problem in one sentence.
4. Identify target user(s).
5. Identify the painful workflow.
6. Define input, process, output and measurable result.
7. Identify roles and permissions.
8. Separate must-have MVP features from nice-to-have features.
9. Classify the architecture:
   - enterprise management
   - booking
   - marketplace
   - community
   - AI business workflow
   - other
10. Propose the smallest robust stack consistent with the existing repository.
11. Identify external APIs and AI opportunities only where they create real value.
12. Define a vertical slice.
13. Produce acceptance criteria.
14. Produce a time-boxed implementation plan.
15. Do not begin broad polishing until the vertical slice is working.
